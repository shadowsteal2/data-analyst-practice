### Estructura

Cada ejercicio vive en su propia carpeta numerada ('01\\\_', '02\\\_'...). Dentro, solo existen las subcarpetas de herramienta (`sql/`, `python/`, `powerbi/`) que realmente se usaron en ese ejercicio. El README de cada ejercicio detalla objetivo, datos y checklist.
